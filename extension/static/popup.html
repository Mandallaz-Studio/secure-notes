Secure Notes

Recevoir une note

Préparation…

  1. Dans Secure Notes, ouvrez la note à envoyer.
  2. Touchez Partager, puis QR code sur un lien.
  3. Scannez ce code : la note s’ouvre dans un nouvel onglet.

Chiffré de bout en bout : le serveur ne voit pas le lien. Ce code sert une fois et disparaît à la fermeture de cette fenêtre.
