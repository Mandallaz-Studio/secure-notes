Serveur

Le téléphone dépose le lien sur le serveur où il se synchronise ; cette extension doit relever au même endroit. Laissez vide pour utiliser le serveur de Secure Notes ().

Un serveur autre que celui de Secure Notes ne voit pas plus le contenu des liens, mais apprend l’adresse IP de ce navigateur. Les notes reçues s’ouvrent toujours sur .
